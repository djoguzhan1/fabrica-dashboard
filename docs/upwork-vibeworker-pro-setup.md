## 1) Kur (10 dk)

### Android (önerilen — kilit ekranı push)

1. Play Store → **Vibeworker: Alerts for Upwork** → yükle.
2. Aç → hesap (e-posta / Google).
3. Onboarding:
   - Ne yapıyorsun: *WordPress bug fixes, page speed, local business landing pages (HTML/CSS), Google Sheets/Excel cleanup, small Python scripts.*
   - **Hunting mode:** **Quick Wins** (0 review için — FAQ: net deliverable, verified client, tek oturumda kapanan işler).
4. **Upgrade → Pro** ($19/ay). Pro şart: **anında alert + Upwork link + sınırsız proposal draft**.
5. Telefon: **Ayarlar → Uygulamalar → Vibeworker → Bildirimler** → **Açık**, ses açık.

### iOS

App Store → Vibeworker → aynı adımlar.
